Bagaimana cara mengikuti cerita?

Tekan Mulai Cerita, pilih bab pada navigasi, atau gulir halaman. Setelah membaca, tekan Tandai sudah dibaca. Arahkan kursor atau fokus keyboard ke titik pada foto pembuka untuk melihat nama tempat; klik atau sentuh untuk membaca penjelasan. Escape menutup penjelasan. Pada bab 5, buka Dengar, Catat, dan Ceritakan untuk menemukan langkah kecilmu.

Di mana progresku disimpan?

Progres cerita tersimpan di browser perangkat ini. Tombol Ulangi progres cerita hanya menghapus progres membaca. Server hanya menambah hitungan kunjungan per bab tanpa nama, alamat IP, atau cookie.

Apakah perlu internet?

Tidak saat aplikasi sudah terpasang dan server lokal berjalan. Buka melalui alamat server, bukan dengan mengeklik file HTML. Tautan sumber membutuhkan internet jika ingin dibuka. Mematikan server akan membuat halaman tidak bisa dimuat ulang.

Dari mana cerita dan fotonya?

Angka rujukan pada paragraf menuju daftar sumber di bawah. Cerita memadukan informasi dari pemerintah daerah, penelitian, dan UNESCO dengan pengantar serta ajakan original Jejak Mbako. Latar pembuka merupakan kolase kreatif berbantuan AI dari dua foto. Foto bab berasal dari kiriman pengguna; rincian kredit dan hal yang belum dikonfirmasi tersedia pada Tentang foto.
